## 공통 규약

**에러 응답**

```json
{ "detail": "사람이 읽을 수 있는 메시지" }
```

| 상태 코드 | 언제 |
|---|---|
| 200 | 정상 |
| 422 | 요청 파라미터가 스키마에 안 맞음 |
| 500 | 서버 처리 실패 |

**페이지네이션** — 방식. 없으면 "없음"과 그 이유.

**공통 헤더** — 모든 요청/응답에 붙는 것. 없으면 "없음".
